# EXP-D3-05-R1 最终决策 — 归纳保持性审查

## 决策

**A — 归纳路线成立，局部 opening 足以支撑设计；可以进入“是否写 Halo2 原型”的下一轮评估。**

限定语必须同时读出：

- 归纳证明是**有条件成立**：前提是 `Inv(S0)` 由可信锚定与一次性 host 跨结构检查建立；
- 局部 opening 的充分性是**设计层结论**：8 类约束族尚未写成 Halo2；
- 成本结论是**置换数量层面的理论预期**：不是 proving time 实测；
- E-R1 继续作为语义基线，本轮没有削弱、替换或修改它。

## 一句话结论

若 S0 的 GR/RR/IR 满足补强后的三态一致性，则 Grant/Revoke 的局部同步更新保持该一致性；`IR(x)=ACTIVE ⇒ x∉RR` 不再需要逐事件全树扫描 RR 来证明，而是由可信 S0 + 归纳步 + 局部约束共同保证。上一轮 D3-05 的核心阻断因此被解除到设计层。

## 为什么是 A，而不是 B

上一轮 B 的理由是“IR↔RR 一致性没有无需全树扫描的证明路径”。本轮给出了该路径：它不是一条单独的 Merkle opening，而是**归纳不变量**：

\[
Inv(S_0) \land \bigwedge_{i} \bigl(Inv(S_i)\land \text{局部同步转换}\Rightarrow Inv(S_{i+1})\bigr)
\Rightarrow IR_i(x)=ACTIVE \Rightarrow x\notin R_i.
\]

因此“电路约束尚未实现”不再构成 B 意义上的**关键设计未闭合项**，而是工程实现项。B 的定义要求数学虽成立但电路约束/初始状态/成本仍有关键未闭合项；本轮三项均给出可落地设计：

- 电路约束：8 类约束族已列明（虽未编码）；
- 初始状态：S0 检查清单已列明（虽未补全实现）；
- 成本：置换净下降方向明确（虽未实测时间）。

## 为什么不是 C

没有发现无法合理解决的逻辑或认证缺陷：

- 截断键碰撞由单槽 opening 的 `full_id` 检查局部拒绝，不引入全局扫描；
- 完整 ID 绑定由 `ir-full-id-eq` + `ir-slot-low-t` 局部约束；
- GR/RR 槽位无需改成 IR 的低位映射，保留各自语义即可；
- 12 个反例全部有明确的拒绝路径。

所以不存在“放弃 IR、只能保留 E-R1”的结论。E-R1 仍是基线，但不再被视为唯一可行语义构造。

## 进入原型前必须完成的工程门槛（不在本轮范围）

1. 在 host 层补 S0 跨结构一致性检查：GR/RR 重复 ID、孤立 RR、IR 与 GR/RR 三态一致、IR 槽位碰撞。
2. 实现 `C_v2` 域分离与 `transition_version`，保持 8 个 public value 数量。
3. 实现 8 类 IR 约束族，特别是 `ir-collision-reject` 与 `IR_in[1]==IR_out[0]`。
4. 与 E-R1 同轮实测 K、proof size、keygen/prove/verify；不得以理论置换数替代时间结论。
5. 明确 `key_field` 单射、revoker 权限、新鲜性/跨证明重放仍为外部信任，不因 IR 引入而自动解决。

## 最终结论

归纳保持性审查通过（有条件）。IR 路线在数学与认证结构层面成立，具备替代逐事件 GR/RR 全树扫描的资格；下一轮可以评估最小 Halo2 原型，但必须先完成 S0 host 检查与 `C_v2`/IR 约束实现，并以同轮实测决定是否真的优于 E-R1。
